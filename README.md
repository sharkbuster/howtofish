# 渔力全开 · 2D 致敬版

把「钓鱼」和「打鱼」荒诞结合起来的 2D 网页游戏。**单个 HTML 文件、零依赖、双击即玩。**

玩法灵感来自 Steam 上的 [How to Fish（渔力全开）](https://store.steampowered.com/)：那款游戏的核心笑点是 ——
**钓鱼只是个开始。鱼钓上来会变成「疯鱼」乱蹦，你得抄起家伙把它打晕，不然它蹦回海里，你就白钓了。**

原版是 3D 物理联机游戏。这里用纯原生 JavaScript 做了一个 2D 单机致敬版，保留了核心循环和大部分笑点。

---

## 核心循环

```
钓鱼 → 打晕疯鱼 → 捡起来卖钱 → 升级装备 → 完成岛屿目标 → 打败 BOSS → 下一座岛
```

### 1. 钓鱼本身就是个两段小游戏

- **按住 `空格` 蓄力**决定抛多远，松手甩出去
- 浮标落水后等鱼咬钩（出现 `!`）
- **按住收线，但张力条顶到头就断线** —— 得看准了松手

张力涨得比落得快，所以你必须反复「按住 → 松手 → 按住」。鱼越大挣扎越凶，节奏越紧。

### 2. 然后才是正片

- 鱼一上岸就变成**疯鱼**，撒腿往海里蹦。**它蹦回去你就白钓了**
- 用拳头打晕它（后面可以买指虎、砍刀、手枪、霰弹枪、狙击枪）
- 打晕的鱼头上会转圈圈，走过去自动卖钱

### 3. 危险不只来自水里

- **海鸥会俯冲下来抢你打晕的鱼**，叼着就往天上飞。可以开枪把它打下来，鱼会掉回沙滩
- **河豚和翻车鱼会撞人**，掉血
- **枪会卡壳**，按 `R` 上膛
- 没血了会「醉倒」，几秒后自己爬起来，无限复活

### 4. 三座岛，三个 BOSS

| 岛屿 | BOSS | 行为 |
|---|---|---|
| 新手码头 | 蜘蛛蟹 | 横扫冲撞 |
| 鬼畜浅滩 | 大河豚 | 环形弹幕 / 三向瞄准 |
| 最终礁石 | 巨型海胆 | 扇形拍地 + 弹幕 |

鱼获装满就会触发 BOSS 上岸。

## 操作

| 按键 | 功能 |
|---|---|
| `空格` | 抛竿 / 收线（按住蓄力） |
| `鼠标左键` | 攻击（打鱼 / 打 BOSS / 打海鸥） |
| `A` `D` | 左右移动 |
| `B` | 打开商店 |
| `R` | 清除卡壳 |
| `P` | 暂停 |
| `M` | 静音开关 |

## 怎么玩

**双击 `index.html`** 就行。不需要装任何东西，不需要联网，不需要构建。

---

## 技术实现

- **纯原生 JavaScript**，无框架、无依赖、无构建步骤
- 单个 HTML 文件，Canvas 2D 渲染
- 逻辑分辨率 1024×576，按窗口等比缩放并加黑边，适配任意屏幕
- 所有美术都是代码画的几何图形，**没有一个图片资源**
- 音效用 **WebAudio 实时合成**，**没有一个音频文件**
- 存档（解锁进度）用 `localStorage`

## 测试

这个项目带了一套**无头测试**（`_verify.js`）。它用模拟的 DOM / Canvas 把游戏真跑起来，可以断言游戏内部状态，不需要浏览器也不需要显卡。

写这套测试是有回报的 —— 它抓出了**两个只有真跑起来才会暴露的 bug**：

1. **BOSS 一被打死，游戏就崩溃。**
   `damageBoss()` 里引用了一个未定义的变量 `isl`，抛 `ReferenceError`。
   也就是说，这个游戏原本**根本通不了关** —— 只要打死任意一个 BOSS 就报错。

2. **BOSS 掉落的鱼永远拿不到。**
   掉落物生成在 `x ≈ 480~960`，而「鱼蹦回海里」的判定线是 `468`。
   所以它们落地的第一帧就被判定为逃跑、直接销毁，玩家永远看不到这份奖励。

另外还修了一个隐患：狙击枪子弹速度 1600 px/s，每帧位移 26.7 px，而小鱼的命中判定窗口只有约 24 px —— **子弹会直接穿过去打不中**。改成按 ≤7px 分步推进后正常了，同时给穿透弹加了命中记录，避免同一条鱼被重复结算。

### 跑测试

```bash
node _verify.js index.html
```

> 需要 [Node.js](https://nodejs.org/)。测试用的是纯 JS，不依赖任何 npm 包。

覆盖 **86 项断言**：完整的钓鱼流程（抛竿 → 咬钩 → 收线 → 上岸）、断线、鱼逃逸、近战/远程/穿透/卡壳、商店全部购买与等级上限、海鸥抢鱼与击落、三个 BOSS 的完整击杀、三岛递进、大鱼撞人、死亡复活……以及一段 3 分钟随机乱玩的冒烟测试（约 770 万次绘制调用，零异常）。

## 已知限制

- **只有单机，没有联机** —— 原版的乐趣有一半在多人互坑
- 没有移动端触屏适配
- BOSS 只有 3 种，行为模式比较固定，重复玩会腻
- 没有背景音乐
